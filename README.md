# 庫存管理系統

用瀏覽器開啟的庫存程式，支援貨品目錄、入庫／出庫、盤點表同盤點封存。

**公開網址：** https://hoyau1992.github.io/inventory-app/

## 第一次使用

這個公開倉庫**沒有放你的庫存資料**（避免數量同出入庫紀錄被公開看到）。

1. 用瀏覽器打開上面的網址，會先看到「庫存表」一覽。
2. 若這個瀏覽器已經匯入過資料，會自動變成「庫存表 1」，內容保留。
3. 要加入另外的 Excel，請先按「新增庫存表」，打開該表後再按「匯入 Excel」；或者按「還原 JSON」還原備份。同一份網站可管理多份互不混合的庫存表，請不要把多份表匯入同一份庫存表。
4. 之後同一部裝置、同一個瀏覽器會按庫存表分開記住資料。

## OneDrive 同步

必須先在這個公開 HTTPS 網站按「登入 Microsoft」，並且使用智祥運通有限公司的 Microsoft 帳戶；未登入時看不到庫存功能。登入後，各份庫存表會同步到該帳戶的 OneDrive，換電腦或手機打開同一網址並以同一個公司帳戶登入即可共用。其他公司或個人 Microsoft 帳戶無法登入。請不要用 `file://` 本機檔案開啟來登入。

- 資料會放在你的 OneDrive 資料夾 `Apps/庫存管理系統`（實際資料夾名稱會跟隨 Entra 應用程式顯示名稱）。
- 程式只申請該應用程式資料夾的權限（`Files.ReadWrite.AppFolder`），不會讀寫你整個 OneDrive。
- 登入用的是公開的應用程式識別碼（client ID），沒有用戶端密碼（client secret）。
- 未登入時，資料仍然只存在該瀏覽器；登出後會停止自動上傳，本機資料會保留。

## 本機離線使用

若要離線開啟，請用完整資料夾（含 `vendor/xlsx.full.min.js`），用 Chrome 或 Edge 打開 `index.html`。網站版改為從 CDN 載入 SheetJS 0.18.5（Apache 2.0）。

## 請勿把庫存資料提交到這個倉庫

不要把含有現存量、入庫／出庫紀錄的 `js/data.js`、Excel 或 JSON 備份 commit 上去。這個倉庫是公開的。
